# README.TXT — Projeto AuditBot

## 1. Sobre o Projeto

Nome do Projeto: AuditBot
Tema: Finanças — Conciliador Inteligente

O AuditBot é um sistema acadêmico desenvolvido para automatizar processos financeiros relacionados ao controle de contas a pagar e a receber.

A proposta do projeto é reduzir o trabalho manual no processamento de notas fiscais, automatizando tarefas como leitura de documentos, validação de dados, identificação de divergências e geração de relatórios.

O sistema utiliza conceitos como OCR, conciliação financeira e categorização de gastos, sempre considerando um contexto de MVP acadêmico, com escopo reduzido e foco em aprendizado.

---

# 2. Objetivo do Projeto

Automatizar processos financeiros relacionados a notas fiscais, aumentando a eficiência operacional e reduzindo erros manuais.

Objetivos principais:

* Automatizar leitura de notas fiscais
* Validar e organizar dados financeiros
* Realizar conciliação com pedidos de compra
* Identificar divergências automaticamente
* Classificar gastos
* Gerar relatórios financeiros

# 4. Processos BPMN

O projeto possui 6 processos principais modelados em BPMN:

1. Processamento de Nota Fiscal
2. Conciliação com Pedido de Compra
3. Geração de Relatórios
4. Identificação de Divergências
5. Classificação de Gastos
6. Armazenamento e Auditoria

Os processos utilizam elementos BPMN como:

* Eventos de início, intermediários e fim
* Gateways
* Tarefas manuais, de usuário e de serviço
* Subprocessos
* Raias
* Objetos de dados
* Armazenamento de dados
* Anotações

Ferramenta utilizada:

* Bizagi
